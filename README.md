
# Hyper Mart Sales Dashboard 📊

## Project Overview
The **Hyper Mart Sales Dashboard** is an interactive Excel dashboard designed to analyze sales performance across different categories, customer segments, regions, and states. This project uses the Superstore sales dataset to transform raw data into meaningful business insights through PivotTables, PivotCharts, and interactive filters.

## Objectives
- Analyze month-wise sales performance.
- Compare sales across different regions.
- Understand sales distribution by customer segment.
- Identify the top 4 sub-categories based on profit.
- Analyze the top 5 states by order-wise sales.
- Visualize category-wise sales distribution.

## Tools & Technologies
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Slicers and Filters
- Data Analysis and Visualization

## Dashboard Features
1. **Month-wise Sales:** Visualizes sales performance across customer segments.
2. **Region-wise Sales:** Compares sales across different geographical regions.
3. **Segment-wise Sales:** Displays sales distribution among Consumer, Corporate, and Home Office segments.
4. **Top 4 Sub-Categories by Profit:** Highlights the leading sub-categories based on profit.
5. **Top 5 States by Sales:** Compares sales performance across the top-performing states.
6. **Category-wise Sales:** Shows the distribution of sales across Furniture, Office Supplies, and Technology.

## Dataset
The project uses a Superstore sales dataset containing information such as:
- Order ID and Order Date
- Customer Name and Segment
- Region, State, and City
- Product Category and Sub-Category
- Sales, Quantity, Discount, and Profit
- Returned orders and regional managers

## Key Learnings
- Data cleaning and preparation in Excel.
- Creating PivotTables for summarizing sales data.
- Building interactive dashboards using PivotCharts.
- Analyzing sales, profit, customer segments, and regional performance.
- Presenting business insights through data visualization.

## How to Use
1. Download or clone this repository.
2. Open the Excel workbook in Microsoft Excel.
3. Navigate to the dashboard worksheet.
4. Use the available filters to explore sales data by category, segment, and other dimensions.
